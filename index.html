    Repositorio de actualizaciones

    Un repositorio público de GitHub solo para las versiones (instalador y backend). Crealo con un README para que no quede vacío. El panel sube cada versión como Release (hasta 2 GB por archivo; el límite de 25 MB es solo para archivos subidos al código del repositorio). Las cajas bajan de ahí el instalador.

    GitHub → Settings → Developer settings → Fine-grained tokens → acceso solo a ese repositorio, permiso Contents: Read and write. Queda guardado solo en este navegador, nunca en el servidor.
